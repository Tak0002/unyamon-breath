# うにゃもん呼吸室

iPhoneのホーム画面から使える、ログインなしの呼吸サポートPWAです。

## アクセスURL

https://tak0002.github.io/unyamon-breath/

## 画面

- 呼吸法選択
- 呼吸セッション
- 端末内の最近の記録
- 音/振動の設定

## GitHub Pages

GitHub Pagesで `main` ブランチのリポジトリ直下から公開しています。

## 素材

- `assets/unyamon-room.jpg`: Google Driveの「うにゃもん」フォルダから取得した既存素材
- `assets/icons/`: 既存素材を参照して生成したPWAアイコン
