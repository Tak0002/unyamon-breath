# うにゃもん呼吸室

iPhoneのホーム画面から使える、ログインなしの呼吸サポートPWAです。

## アクセスURL

https://tak0002.github.io/unyamon-breath/

## 画面

- 呼吸法選択
- 呼吸セッション
- 端末内の最近の記録
- 音/振動の設定

## GitHub Pages

GitHub Pagesで `main` ブランチのリポジトリ直下から公開しています。
